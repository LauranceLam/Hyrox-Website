# Hyrox Website

A clean, lightweight landing page for a Hyrox-inspired fitness brand.

## Features

- Hero section with strong fitness branding
- Program overview cards
- Challenge and training highlights
- Responsive layout for mobile and desktop

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server such as:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
